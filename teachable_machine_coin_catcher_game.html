相機卡住排查與 GitHub Pages 部署提示

  • 相機權限： 首次開啟時瀏覽器會詢問是否允許使用攝影機，務必點擊「允許 (Allow)」。若之前封鎖過，請點擊網址列左側的相機圖標解除封鎖。
  • 其他軟體佔用： 請確保 Zoom、Line 或其他視訊軟體沒有在背景獨占您的網頁攝影機。
  • 安全性限制 (HTTPS)： 上傳到 GitHub Pages 後必須透過 https:// 網址才能順利調用相機（本機開發時 http://localhost 或 127.0.0.1 也支援）。
